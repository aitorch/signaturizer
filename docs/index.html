Everything you need to sign PDFs

Built for speed, privacy, and automation.

Webcam Signature Capture

Hold up your signature on paper — the webcam captures it in real time. No scanners, no image files.

Adaptive Paper Cleanup

Intelligent thresholding removes shadows and paper texture, leaving a crisp, clean signature.

Visual Placement & Resize

Click anywhere on your PDF to drop the signature. Drag, scale, and rotate with live preview.

Color Tinting

Switch between classic black, standard blue ballpoint, or pick a custom hue — all applied non-destructively.

100% Local & Private

No uploads. No cloud. No telemetry. Your documents never leave your machine.

HTTP API for Automation

Built-in REST endpoint lets you sign PDFs programmatically — perfect for batch jobs and pipelines.

PDF Text Extraction

Read form fields and labels directly from the PDF, so you know exactly where to sign.

OCR with Tesseract

Scanned documents? Built-in Tesseract OCR extracts text from image-based PDFs automatically.

How it works

From unsigned to signed in under 30 seconds.

1

Open a PDF

Drag in any PDF document. It renders instantly with pdf.js — no loading spinners.

2

Capture your signature

Hold your signed paper up to the webcam. The adaptive cleaner strips background noise.

3

Click to place

Click anywhere on the document. Resize, rotate, and tint until it looks just right.

4

Save your signed copy

Export a flattened, signed PDF with pdf-lib. Ready to email, print, or archive.

Your documents never leave your computer

Signaturizer processes everything locally. No file uploads, no cloud APIs, no analytics, no accounts. What happens on your machine stays on your machine — exactly how signing a legal document should be.

Built with a modern stack

# Clone the repository git clone https://github.com/pixeleldev/signaturizer.git cd signaturizer # Install dependencies npm install # Launch in dev mode npm run dev
